# The Robot Apology

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)
[![competition](https://img.shields.io/badge/competition-u--suga--the--robot--apology--dd96bb59-green)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)
[![license](https://img.shields.io/badge/license-MIT-yellow)](LICENSE)

A two-line robot confession for the [make.fun bounty "The Robot Apology"](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) ($2).

Line one is a robot apologizing in a single sentence for one specific mistake.
Line two is one sentence about what the robot learned and what it will do
differently — the lesson follows from that exact mistake.

## Run

```sh
python3 main.py
```

This writes the two-line entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
